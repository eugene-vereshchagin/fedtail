# fedtail

*`tail -f` по федиверсу.* Десктопный клиент для GoToSocial, Mastodon, Akkoma и всего, что
говорит на Mastodon API. Для тех, кто помнит Juick и Point.im и устал читать обрывки чужих
разговоров.

Клиент для тех, кто устал искать и вспоминать, откуда пришёл ответ и о чём вообще шла речь.
Для тех, кто отвлекается на тууты от работы и своих занятий и потом совершенно не помнит
контекст разговора. Поэтому главное здесь — вернуть этот самый контекст: над каждым ответом видно, на
что он отвечает; под чужим комментом — что ты сам на него сказал; тред открывается деревом на
том месте, откуда ты пришёл; лента помнит, где ты остановился, и не прыгает.

[English version](README.md)

> Статус: ранняя разработка (0.1). У автора работает, шероховатости будут.

## Чем отличается

- **Ничего не прыгает.** Лента открывается на первом непрочитанном. Новое приходит снизу и не
  сдвигает то, что ты читаешь. Читаешь по хронологии, как RSS.
- **Каждый ответ показывает, на что он отвечает.** Над ответом — полоска с началом исходного
  поста; клик открывает весь разговор.
- **Треды — деревом.** Отступы по глубине, комменты пронумерованы `/1 /2 …`, пост, откуда
  пришёл, подсвечен.
- **Ленты раздельно и по группам.** «Стандартные» — от самой широкой: Федерация, Лента,
  Локальная, Боты; «Личные» — Мои записи, Упоминания, Ответы мне, Подписки, Закладки, Лайки и
  бусты, Заявки; внизу — «Списки».
- **Приватно по умолчанию.** Новый пост — только подписчикам; ответ никогда не открытее исходного.
- **Черновики не теряются.** Текст сохраняется на лету, закрыл окно — ничего не пропало.
- **Конфиг-файл вместо окна настроек.** Любое поведение — флаг. По умолчанию — как удобно
  автору; «как у всех» — одна строчка.
- **Один профиль = один аккаунт = одно окно.** `--profile work` — второй аккаунт.

## Для тех, кто с Juick и Point

fedtail задуман как клиент «по-поинтовски» поверх федиверса: читаешь ленту по порядку и не
теряешь, где остановился; каждый коммент виден в своём треде; треды деревом с нумерацией
`/1 /2 …`, целиком — ответы, которых нет на твоём сервере, подтягиваются с сервера автора;
подписка на треды (как `S #abc` на Point) и командная строка: `#abc текст`, `S #abc`, `@user`;
приватность по умолчанию. Попробовать и прислать отзыв: [docs/TESTING.md](docs/TESTING.md).

## Запуск из исходников

Debian 13 (trixie) и новее:

```sh
sudo apt install python3-pyside6.qtwidgets python3-pyside6.qtdbus python3-requests \
    qt6-image-formats-plugins
git clone https://github.com/eugene-vereshchagin/fedtail.git
cd fedtail
python3 -m fedtail
```

**Как запускать.** Из папки с исходниками работают обе формы:

```sh
python3 -m fedtail           # «модулем» — правильный способ
python3 fedtail              # папкой — тоже работает
```

Ключи у обеих одинаковые: `python3 -m fedtail --profile croco`, `python3 fedtail --update-config`
и т. д. Короткая команда `fedtail` без `python3` появится, когда программа будет поставлена
пакетом (deb — в планах); до тех пор в примерах ниже подставляй `python3 -m fedtail`.
Все ключи: `python3 -m fedtail --help`.

Если в постах вместо эмодзи и флагов квадратики — нет цветного шрифта эмодзи:
`sudo apt install fonts-noto-color-emoji`.

Где угодно ещё с Python ≥ 3.11: `pip install requests PySide6-Essentials`, дальше так же.

**Windows** (пока проба): в [релизах](https://github.com/eugene-vereshchagin/fedtail/releases)
лежит `fedtail-…-windows.zip` — распакуй куда угодно и запусти `fedtail.exe`, Python не нужен.
`fedtail.exe --install-desktop` добавит ярлык в меню «Пуск». Конфиг — в
`%APPDATA%\fedtail\<профиль>\`, данные — в `%LOCALAPPDATA%\fedtail\<профиль>\`,
уведомления — через значок в трее. Из исходников — так же, как выше, через
`pip install requests PySide6-Essentials` и `python -m fedtail`.

При первом запуске fedtail спросит адрес сервера, откроет страницу входа в браузере и будет
ждать код, который покажет сервер. Заходи обычной учёткой, не админской.

Обновиться: `git pull` в папке и перезапустить.

## Профили и файлы

Аккаунт — это профиль: свой конфиг (а значит, своя тема), свои данные, своё окно.

```sh
python3 -m fedtail                        # профиль "default"
python3 -m fedtail --profile croco        # другой аккаунт (в первый раз — окно входа)
python3 -m fedtail --profiles             # какие профили есть и кто в них
python3 -m fedtail --install-desktop --profile croco   # отдельный пункт в меню KDE
python3 -m fedtail -c ~/my.toml -d ~/fd/  # явно: файл конфига и папка данных
```

В окне — правый клик по своей аватарке (или ≡ → Аккаунты): список остальных аккаунтов;
выбрал — открылось его окно в его теме, а это закрылось (`ui.switch_closes = false` — останутся
оба). «Добавить аккаунт…» спросит имя профиля и откроет окно входа.

Или все аккаунты в одном окне (там же, «Все аккаунты в одном окне», или
`ui.merge = ["all"]`): ленты с одинаковыми именами сливаются («Лента» обоих — одна), списки
других аккаунтов — отдельными лентами, а пост, полученный другим аккаунтом, помечен «→ @work»:
ответ, лайк и буст уйдут от него. Новые посты, командная строка, «Лайки и бусты» и заявки —
у основного аккаунта.

| что | где |
|---|---|
| конфиг (программа только читает) | `~/.config/fedtail/<профиль>/config.toml` |
| токен, права 0600 | `~/.local/share/fedtail/<профиль>/auth.json` |
| кеш, прочитанное, черновики | `~/.local/share/fedtail/<профиль>/state.db` |
| картинки | `~/.local/share/fedtail/<профиль>/cache/` |

Конфиг создаётся при первом запуске — полностью закомментированная копия
[`fedtail/data/config.example.toml`](fedtail/data/config.example.toml). Дальше программа его не
трогает: правь, перезапускай. Рядом всегда лежит `config.example.toml` — полный справочник
опций текущей версии. Появились новые опции — fedtail скажет об этом при запуске, а
`python3 -m fedtail --update-config` допишет их в твой конфиг закомментированными, в нужные секции,
обновит пояснения к тем, что уже есть (новые темы, новые варианты), и уберёт закомментированные
опции, которых больше нет (старый файл останется как `config.toml.bak`; твои значения и
заметки не трогаются). Ошибся в значении — fedtail при старте скажет, в какой строке и что
допустимо. «Всё сломал» — удали файл, при следующем запуске появится чистый.

Повторный запуск того же профиля не открывает второе окно, а поднимает уже открытое.

## Темы

Внешний вид — это файл темы. Встроенные:

- `system` — светлая или тёмная, как настроен KDE: все цвета берутся из системной палитры;
- `terminal` — зелёным по чёрному, всё моноширинное, посты разделены линиями, кнопки словами.
- `juick` — juick.com году в 2013-м: светло-серая страница, белые посты, синие ссылки.
- `juick-classic` — juick.com году в 2011-м: оливковый фон, бежевые посты, рыжие ссылки.
- `point` — point.im сегодня: белая страница, посты через тонкую линию, Open Sans.
- `night` — тёмная, своими цветами, на любом рабочем столе.
- `contrast` — для слабого зрения: крупно, чёрным по белому, чёткие линии.
- `pink` — розовая: пудра и ягодные ссылки, мягкие углы, цветочки.
- `nord` — арктическая тёмная: холодный сине-серый, морозные ссылки.
- `solarized` — Solarized light: тёплая бумага, синие ссылки.
- `paper` — тёплая бумага и книжный шрифт, для длинных тредов.

Выбор — в конфиге: `[ui] theme = "terminal"`. Свои темы кладутся в `~/.config/fedtail/themes/<имя>.toml`
(общие для всех профилей). Рядом, в `builtin/`, всегда лежат свежие копии встроенных — с них удобно
начинать. Проще всего унаследовать готовую тему и поменять пару строк:

```toml
name = "Мой зелёный"
inherit = "terminal"

[colors]
text = "#a8ff60"
```

В теме настраиваются цвета, шрифты, скругления, вид карточек (рамками или линиями), аватары,
иконки и даже подписи — `[ написать ]`, `== люди ==`, `---- дальше новое ----`. Полный список с
пояснениями — `builtin/system.toml`. Ошибку в теме fedtail покажет в строке состояния и откатится
на `system`.

## Ленты

«Ответы мне» — все ответы на твои посты и комменты; «Упоминания» — остальное: где тебя
тегнули в чужом разговоре. Ответ тебе с `@тобой` внутри — это ответ, в «Упоминаниях» он не
дублируется. Хочешь видеть там вообще всё — `lanes.mentions_all = true`.

**Подписки**, как на Point. Сервер сообщает только об ответах, где тебя упомянули: если двое
отвечают друг другу под твоим постом, ты об этом не узнаешь. fedtail сам следит за тредами и
складывает новое в них в «Подписки». На свои посты и треды, где ты комментишь, подписка
ставится сама; на любой другой тред — в меню ⋯ у поста или кнопкой «Подписаться на тред» в его
заголовке. Отписка запоминается: напишешь там снова — тред не вернётся. Настройки — в `[subs]`
(как часто проверять, когда бросать затихший тред, на что подписываться самому).

## Списки

Списки с твоего сервера (Mastodon, GoToSocial) — отдельные ленты в своём блоке под основными.
Правый клик по посту (или меню ⋯) → «В список»: галкой добавить автора в любой список или в
новый. Правый клик по списку — переименовать, удалить, сделать **исключающим**: кто в таком
списке, того нет в «Ленте» и «Ботах», только там. Так ботов можно разложить на «Мемасики»,
«Новости» и остальное. Настройки — `[lists]`.

## Найти людей и теги

Строка поиска под «Написать» (`Ctrl+K`) находит людей — по имени, `@ник@сервер` или ссылке на
профиль, — теги и посты, с кнопкой «Подписаться» прямо в результатах. На теги тоже можно
подписаться: посты с ними пойдут в «Ленту». В профиле — «Читает N» и «N читателей», у каждого
человека кнопка «Подписаться»: проще всего находить новых людей через тех, кого уже читаешь.

## Командная строка, как на Point

Внизу окна (`Ctrl+L`): `#a3f` — открыть пост, `#a3f текст` — ответить, `#a3f/2 текст` —
ответить на коммент /2 его треда, `S #a3f` / `U #a3f` — подписаться на тред и отписаться,
`S @ник` / `U @ник` — подписаться на человека и отписаться, `! #a3f` — продвинуть,
`~ #a3f` — в закладки, `D #a3f` — удалить свой пост, `@ник` — профиль, `@ник текст` — личное
сообщение, просто текст — новый пост, `?` — справка. Пока печатаешь, справа написано, что
сделает Enter: на какой пост уйдёт ответ и кто его увидит. `↑` `↓` — прошлые команды.

**Разговоры**: кнопка над лентой показывает каждый разговор один раз — с чего начался, сколько
в нём сообщений и сколько новых, кто написал последним.

## Тишина

Меню ⋯ у поста (или профиль) — заглушить или заблокировать автора: его посты сразу пропадают
из всех лент. ≡ → «Тишина…» — фильтры по словам (хранятся на сервере): «свернуть» — пост
виден свёрнутым с пометкой, «скрыть» — не виден вовсе; там же списки заглушённых и
заблокированных, с отменой.

## Ссылки — внутри

@упоминания открывают профиль человека во вкладке (о себе, поля, «читает тебя», Подписаться,
Упомянуть, В список), #хэштеги — ленту тега, ссылки на посты и профили с других серверов
ищутся через твой сервер и открываются тредом или профилем; в браузер уходит только то, что
fedtail не нашёл. `ui.links_in_app = false` — всё в браузер, как раньше.

## Честные счётчики и читаемые хэштеги

Твой сервер знает только те лайки и бусты, что дошли до него. С `feed.honest_counters = true`
fedtail, открывая тред, спрашивает у сервера автора каждого публичного поста настоящие числа
(без твоего токена, но это запрос с твоего IP — поэтому по умолчанию выключено).

Если хэштег написан одним регистром (`#georgianews`), окно поста подскажет `#GeorgiaNews`:
экранные дикторы читают такое по словам. `post.camelcase_hint = false` — не подсказывать.

## Свой профиль

Клик по своей аватарке или имени в сайдбаре открывает твой профиль во вкладке: посты,
подписчики, подписки и кнопка «Редактировать профиль» — имя, «о себе», аватар, шапка, поля
профиля, подтверждение подписчиков вручную, «это бот», показ в каталоге. На сервер уходит
только то, что ты поменял.

## Уведомления

**Активность** — отдельная лента: кто добавил твои посты в избранное, кто продвинул, кто
подписался — собрано по постам («Кот, Арсен и ещё 3 — ★ в избранное «…»»). Какие события
показывать — `[activity] types`.

Новые комментарии, упоминания и запросы на подписку приходят уведомлениями KDE; кнопка
«Открыть» ведёт прямо в тред. Какие ленты уведомляют и сколько уведомление рассказывает —
в `[notify]`:

```toml
[notify]
lanes = ["comments", "mentions", "requests"]
privacy = "full"     # "sender" — только кто, без текста; "count" — только «3 новых комментария»
```

`privacy = "count"` — для демонстрации экрана и опенспейса: ничего читаемого из окна не утекает.
Пока окно fedtail активно, уведомлений нет (`when_focused = true`, если нужны).

Чтобы была иконка в меню, на панели и в уведомлениях, один раз поставь ярлык:

```sh
python3 -m fedtail --install-desktop          # или --profile work --install-desktop
```

## Написание

Картинки можно перетащить в окно поста (или в главное окно — откроется новый пост) и вставить
`Ctrl+V`, скриншоты тоже. Двойной клик по картинке — подпись к ней. Поле предупреждения (CW)
спрятано за кнопкой «⚠ Предупреждение» (`post.cw_field = true` — показывать сразу).

## Клавиши

| | |
|---|---|
| `S` (в просмотрщике) | сохранить картинку в «Загрузки» (`ui.save_dir`); ещё — правый клик по картинке |
| `Ctrl+K` | поиск людей, тегов, постов |
| `Ctrl+N` | новый пост |
| `Ctrl+Enter` | отправить |
| `F5` | обновить |
| `Alt+1…9` | переключить ленту |
| `Ctrl+W` | закрыть вкладку |
| `Esc` | закрывает то, что сверху (картинку, поиск); последний `Esc` закрывает все ленты шторкой — ничего не отмечается прочитанным, новое копится до утра (`ui.esc = "tray"` — прятать окно в трей) |
| `Ctrl+F`, `F3`, `Shift+F3` | поиск по открытой ленте / треду (текст, имя, `@ник`, `#id`, подписи к картинкам); «Глубже» — по всему сохранённому для ленты |
| `Ctrl+Q` | выйти совсем (крестик только прячет в трей) |

## Если сломалось

Режим отладки (`debug.mode`: сам включён до версии 1.0 и в сборках для разработки, выключен в релизах; `--debug` — на один запуск) пишет журнал в `~/fedtail-logs/<профиль>/`, файл на каждый запуск и
каждый час, `latest.log` — текущий (`debug.log_dir`). Приложи `latest.log` или запусти
`python3 -m fedtail --bug-report` и пришли архив, который появится в домашней папке: журналы,
трассировки падений, конфиг и сводка о системе — без токена и базы. Если окно зависло —
сначала `kill -USR1 <pid>`: запишет, где застрял каждый поток. Подробно —
[docs/DEBUGGING.md](docs/DEBUGGING.md).
