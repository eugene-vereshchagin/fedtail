# fedtail — устройство и ТЗ

Десктопный клиент федиверса (GoToSocial, Mastodon, Akkoma — всё, что говорит на Mastodon API)
для тех, кто помнит Juick и Point.im и кого бесит лапша из обрывков чужих разговоров.

Как это устроено в коде — [ARCHITECTURE.md](ARCHITECTURE.md) (по-английски, подробно);
логи и диагностика — [DEBUGGING.md](DEBUGGING.md).

## Принципы

<!-- include: parts/principles lang=ru -->
1. **Ничего не дёргается.** Открыл ленту — стоишь на первом непрочитанном. Пришло новое —
   позиция не меняется, просто растёт счётчик. Читаешь по хронологии, как RSS.
2. **Каждый ответ знает, на что он отвечает.** Над ответом — полоска с началом исходного
   поста, под чужим комментарием — что ты сам на него ответил: вернулся в тред через неделю —
   сразу видно, где был. Клик открывает весь тред деревом.
3. **Ленты разделены.** Люди отдельно, боты отдельно, ответы мне отдельно от прочих
   упоминаний.
4. **Приватно по умолчанию.** Новый пост — только подписчикам. Ответ никогда не открытее
   исходного.
5. **Любое поведение — ключ в конфиге.** Окна настроек нет и не будет. По умолчанию — как
   удобно автору, «как у всех» включается флагом. Новые возможности приходят выключаемыми.
6. **К чужим серверам — без твоего токена.** Всё, что fedtail берёт с сервера автора
   напрямую по ActivityPub, идёт анонимно: там видят только твой IP.
7. **Ядро не знает про GUI.** Интерфейсы — плагины: окно на Qt, терминал, браузер; дальше —
   GTK.
8. **Один профиль — один аккаунт.** Второй аккаунт — второй профиль (`--profile`); по
   желанию все аккаунты собираются в одном окне (`ui.merge`).
9. **Взрослые разбираются сами.** Режим arts (в честь @arts, основателя Point.im): всё как
   автор выложил, без опеки. Послать можно любого, хоть админа, — и админ может послать в
   ответ.

### Фронтенды

Ядро не знает про GUI, интерфейсы — плагины (`--ui`). Кроме Qt в планах, примерно по порядку:

| фронтенд | для кого |
|---|---|
| **CLI** | `fedtail tail comments` — новые комменты в терминал по мере прихода, `fedtail post "текст"`; скрипты и пайпы |
| **TUI** (Textual) | полноценный интерфейс в терминале, мышь и цвет, работает по ssh |
| **GTK4 + libadwaita** | GNOME, Cinnamon и прочие GTK-столы, чтобы выглядело родным |
| **веб на localhost** | открыть в браузере, в том числе с телефона в домашней сети |
| **Toga** (BeeWare) | нативные виджеты Windows/macOS/GTK/Android/iOS из одного кода; на попробовать |

## Известные ограничения сервера

- Нода уведомляет только об ответах, где тебя упомянули. Ответ двух людей друг другу в твоём
  треде в «Ответы мне» не попадёт — его ловят подписки на треды: клиент сам перечитывает
  треды раз в `subs.interval_minutes`. Видно то, что знает твой сервер: если ни ты, ни кто-то с
  твоей ноды не подписан на автора ответа, сервер может его не получить.
- Ванильный Mastodon не понимает Markdown. Клиент определяет это сам (`account.markdown = "auto"`).
