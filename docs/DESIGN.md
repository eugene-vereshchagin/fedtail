# fedtail — устройство и ТЗ

Десктопный клиент федиверса (GoToSocial, Mastodon, Akkoma — всё, что говорит на Mastodon API)
для тех, кто помнит Juick и Point.im и кого бесит лапша из обрывков чужих разговоров.

## Принципы

1. **Ничего не дёргается.** Открыл ленту — стоишь на первом непрочитанном. Пришло новое —
   позиция не меняется, просто растёт счётчик. Читаешь по хронологии, как RSS.
2. **Каждый ответ знает, на что он отвечает.** Над ответом — полоска с началом исходного
   поста, клик открывает весь тред деревом.
3. **Ленты разделены.** Люди отдельно, боты отдельно, комменты к моим отдельно от прочих упоминаний.
4. **Приватно по умолчанию.** Новый пост — только подписчикам. Ответ никогда не открытее исходного.
5. **Всё поведение — флаги в конфиге.** Окна настроек нет и не будет. По умолчанию — как удобно
   автору, но «как у всех» включается флагом.
6. **Ядро не знает про GUI.** Интерфейсы — плагины. Qt первый, терминальный — потом.
7. **Один запуск — один аккаунт.** Второй аккаунт — второй профиль (`--profile`).

## Архитектура

```
fedtail/
  __main__.py        запуск: профиль, конфиг, блокировка, выбор фронтенда
  i18n.py            строки интерфейса (ru, en)
  core/              БЕЗ GUI, можно тестировать без дисплея
    paths.py         каталоги профиля
    config.py        TOML-конфиг: дефолты, проверка, предупреждения
    auth.py          токен в файле (0600), регистрация приложения
    instance.py      «один профиль — одно окно» через unix-сокет
    api.py           Mastodon API + определение возможностей сервера
    model.py         хелперы над постами: видимость, упоминания, текст
    threads.py       дерево треда, нумерация комментов /1 /2
    store.py         SQLite-кеш профиля: посты, ленты, прочитанное, черновики
    sources.py       источники: home, упоминания, мои, локальная; догонялка по min_id
    lanes.py         ленты = источник + фильтр
    events.py        простая шина событий
    app.py           Core — фасад для фронтендов: потоки, опрос, действия
  frontends/
    __init__.py      реестр фронтендов
    themefile.py     темы: поиск, наследование, проверка (без Qt)
    qt/              Qt Widgets (PySide6)
  data/
    config.example.toml
    themes/          встроенные темы: system.toml (справочник всех ключей), terminal.toml
tools/
  screenshots.py     рендер окна на выдуманных данных; CI кладёт картинки в ветку screenshots
```

Фронтенд получает от ядра события (`lanes_updated`, `status_updated`, `parents`, `notify`, …)
и вызывает методы `Core`. Сетевые вызовы возвращают `concurrent.futures.Future`; фронтенд
сам переносит результат в свой GUI-поток.

### Хранилище

`~/.local/share/fedtail/<профиль>/`:

| файл | что |
|---|---|
| `auth.json` | сервер, client_id/secret, токен. Права 0600 |
| `state.db` | SQLite: посты, элементы лент, прочитанное, черновики, состояние окна |
| `cache/` | картинки |
| `instance.sock` | сокет «уже запущено» |

Конфиг `~/.config/fedtail/<профиль>/config.toml` программа **только читает**. Если его нет —
кладёт туда закомментированный пример и дальше не трогает.

### Чтение без прыжков

Каждый источник догоняется вперёд от самого свежего известного элемента через `min_id`,
страницами, без дыр. Если новых больше `feed.catch_up_limit`, остаток догонится следующим
опросом. Старое подгружается по кнопке «раньше» через `max_id`.

Прочитанное хранится по id поста; пост, прочитанный в одной ленте, прочитан во всех.
Режим отметки — `read.mark_read`: при прокрутке, при открытии ленты или только руками.

## Этапы

| версия | что |
|---|---|
| **0.1** | ядро, конфиг, профили, Qt: ленты, треды деревом, контекст ответа, прочитанное и позиция, черновики, Markdown, заявки в подписчики, трей |
| 0.2 | подписки на треды как на Point (лента «Подписки»); **списки** — серверные списки Mastodon/GoToSocial как ленты слева, «Добавить в список…» правым кликом, исключающие списки (кто в «Мемасиках», того нет в общих «Ботах»); мультиаккаунт в одном окне — попробовать |
| 0.3 | командная строка в стиле Point (`#a3f текст`, `S #a3f`, `@user`), режим «разговоры» |
| 0.2+ | **честные счётчики**: при открытии треда спросить у сервера автора настоящие лайки и бусты публичного поста (флагом: это запрос к чужому серверу); **CamelCase-хэштеги**: подсказка в окне написания писать `#GeorgiaNews`, а не `#georgianews` — экранные дикторы читают по словам |
| потом | deb-пакет с номером сборки (в `/usr`, зависимости из apt), редактирование постов, TUI-фронтенд |

## Известные ограничения сервера

- Нода уведомляет только об ответах, где тебя упомянули. Ответ двух людей друг другу в твоём
  треде в «Комменты к моим» не попадёт — для этого будут подписки на треды (0.2).
- Ванильный Mastodon не понимает Markdown. Клиент определяет это сам (`account.markdown = "auto"`).
