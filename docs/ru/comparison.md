# fedtail и другие клиенты

Те же возможности, что в [полном списке](/docs/ru/features.md), — одной матрицей на главу: есть ли такое у других клиентов. ✓ — есть, пусто — нет или неизвестно. Сведения — из README и заметок к релизам (осень 2026 года) и общих знаний, без проверки каждого вживую; подробности и оговорки — в столбце «У других» полного списка.

У fedtail: ✓ — есть, ◐ — частично, — — нет, ⏳ — в планах.
