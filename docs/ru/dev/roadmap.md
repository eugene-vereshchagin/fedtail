# fedtail: план на 0.21

Что делаем в 0.21 (решено 26 окт 2026, когда 0.20.0 готова к выпуску): **синхронизация
между устройствами — до конца** и **свободные ленты** — ленты, которые собираешь сам.
Пользовательская сторона — в списке фич со статусом «в планах» (`docs/src/features/*.toml` →
`docs/*/parts/roadmap.md` и сайт); здесь — весь план, с разработческой частью.

## Что принесла 0.20

Android как полноценный клиент федиверса (все места, меню ⋯, профили, редактор, push);
терминал и веб со всем, что есть в окнах, и колонки в вебе; медленный режим, «уведомлять не чаще…», «из них
новых»; свои реакции; коллекции, лента чужого сервера, лента ссылки; apt-репозиторий и
установщик для Windows (ждут своих ключей); ответы про устойчивость (`robustness.md`) и
самопроверка с настоящими аккаунтами на Linux, Windows и Android. Всё — в CHANGELOG.md.

## Делаем

| # | что | как поймём, что готово |
|---|---|---|
| 1 | **Синхронизация, проверенная вживую**: Linux, Windows и Android на одном аккаунте через сервер fedtail-sync и через папку; ходят прочитанное, треды, ленты, черновики, активность, плитки; новое устройство не отмечает прочитанным непрочитанное других | шаг самопроверки на двух профилях с одной папкой синхронизации (`tools/selfcheck.py`); то же руками на трёх устройствах |
| 2 | **Синхронизация: то, что сейчас «пока нет»** (`docs/ru/sync.md`): ключ QR-кодом из окна и камерой телефона; картинки черновика едут с ним; WebDAV напрямую; старые журналы упаковываются в снимок | каждое — фича «есть» со своим `since`, список «Пока нет» пуст или с причиной, почему нет |
| 3 | **Синхронизация во всех интерфейсах**: состояние, «синхронизировать сейчас», ключ, ошибки словами — Qt, GTK, терминал, веб, Android одинаково | `tools/parity.py` без строк про синхронизацию; в сценарии поведения есть шаг синхронизации |
| 4 | **Свободные ленты, ядро** (`feeds.md` §9, шаги 1–5): атомы, правила со строгой проверкой и `explain`, встроенные ленты как пресеты (тот же результат, что сейчас), ленты по нескольким источникам, «Неразобранное», «Почему это здесь?», `--explain-lane` | тест на записанном хранилище: пресеты дают сегодняшние ленты пост в пост; каждый ключ и каждая ошибка правила под тестом |
| 5 | **Свободные ленты, снаружи** (§9, шаги 6–7): `[[lanes.custom]]` в конфиге и обоих примерах, фичи и справка; боковая панель, колонки, плитки, уведомления по самой личной ленте во всех интерфейсах | лента из конфига выглядит одинаково в Qt, GTK, терминале, вебе и Android; паритет — 0 расхождений |

## Ждёт решения

- `feeds.md` §10: вложенные группы в `any`; события и посты в одной ленте; `in_my_thread`
  без подписки; редактор лент на телефоне.
- Сервер синхронизации: свой публичный экземпляр проекта или только «поставь свой».
- Решения автора из `robustness.md`: хранилище токена, шифрование базы, проверка новой
  версии, NTLM-прокси, системная тема на ходу, зависшая первая копия.

## Хвосты

- Секреты: `APT_GPG_KEY` и GitHub Pages для ветки `apt`, `WINDOWS_CERT_PFX`.
- Значок в трее, остающийся после выхода из ростера в KDE (раскладка split), — проверить
  на 0.20.0.
- Подвисания при первом щелчке по ленте с множеством карточек (`card.py` `_hint_width`):
  померить на настоящем аккаунте.

## Не в 0.21

Toga; токен из внешней команды; годовой отчёт Mastodon и прочее «не будем» из списка фич.
