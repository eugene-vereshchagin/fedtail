# fedtail: план на 0.19

Что делаем в 0.19 (решено 22 окт 2026, после выпуска 0.18.0). Пользовательская сторона —
в списке фич со статусом «в планах» (`docs/src/features/*.toml` → `docs/*/parts/roadmap.md`
и сайт); здесь — весь план, с разработческой частью.

## Делаем

| # | что | как поймём, что готово |
|---|---|---|
| 1 | **Звуковая схема**: звуки — часть темы, как значки (папка темы, свой набор у мессенджерных тем: новое сообщение, ответ, упоминание, вход), выключаемо; Qt, GTK, по возможности терминал (bell) | фича `sound-scheme` — «есть»; тест: событие → звук темы; без звуковой системы — молча |
| 2 | **Тесты на Windows**: дописать то, что сейчас пропускается или держится только на Linux (пути, ярлык в «Пуск», трей, уведомления, single-instance, отладочные логи); `docs/ru/dev/windows.md` прогоняется целиком | тот же набор, что в CI для Windows, зелёный на твоей виртуалке; пропуски — только то, чего на Windows нет по природе (GTK, `.desktop`, D-Bus) |
| 3 | **Одинаковое поведение тулкитов**: не только слова интерфейса (`tools/parity.py`), но и что делают одни и те же действия в Qt, GTK, вебе и терминале — общий сценарий (открыть ленту, прочитать, ответить, лайк, тред, профиль, меню поста, Esc, выход) на фейковом сервере, одинаковые итоги | `tools/parity.py` + новый сценарный тест; расхождения — в отчёте самопроверки, 0 на релизе |
| 4 | **Полноценный терминал (TUI)**: всё, что есть в окнах, в пределах терминала — меню поста, профиль со всеми кнопками, списки, поиск, тишина, справка, «что нового», настройки аккаунтов | паритет TUI по `parity.md` — как у GTK (≥ 90 % слов), сценарий п. 3 проходит |
| 5 | **Полноценный веб**: то же для веба — списки, тишина, поиск по ленте, правка профиля, заявки, «Активность» с группами, уведомления браузера | паритет веба ≥ 90 %, сценарий п. 3 проходит |

## Хвосты, которые тоже закрываем в 0.19

- GTK: проверить вживую Wayland, сверку цветов с Qt (`SameAsQtTest` в CI), GNOME и XFCE.
- Экранные дикторы: пройти интерфейс с Orca (Qt и GTK), поправить то, что не читается.
- Отображение реакций — есть; ставить свои — когда сервер умеет (GoToSocial — нет).
- Первый запуск на новой машине: проверить вживую на Windows (удалить
  `%LOCALAPPDATA%\fedtail\default` и запустить) — непрочитанное с другой машины сохраняется.
- Группы уведомлений Mastodon 4.3+ — проверить на живом аккаунте.
- Вход в браузере на Windows-виртуалке (сервер получал не тот пароль) — выяснить, что
  меняется при вставке.

токен через `pass`/`gopass`; проверка орфографии (ты говорил — не нужна: перевести в «не
будет»?).
