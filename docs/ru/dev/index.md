# Для разработчиков

fedtail — программа на Python: ядро, которое ничего не знает про GUI, слой протоколов, где
Mastodon — первый протокол, и четыре интерфейса сверху — окно на Qt, окно на GTK, терминал
(Textual) и веб-страница. Большую часть кода пишет нейросеть (Claude) под присмотром
человека; вклад людей и их инструментов оценивается одинаково: по диффу, тестам и тому,
вписывается ли он.

## Запуск, тесты, линтер

```sh
python3 -m fedtail                       # запуск из исходников (нужны PySide6 + requests)
python3 -m unittest discover -s tests -t .   # все тесты; Qt-шные пропускаются без PySide6
QT_QPA_PLATFORM=offscreen python3 -m unittest tests.test_qt_smoke
xvfb-run -a python3 -m unittest tests.test_gtk_smoke   # окно GTK (python3-gi gir1.2-gtk-4.0)
ruff check .                             # длина строки 100
python3 tools/docs_build.py              # после любой правки docs/src/ или примеров конфига
python3 tools/selfcheck.py --quick       # обходы всех интерфейсов, 5 минут
```

Пакеты Debian 13: `python3-pyside6.qtwidgets python3-pyside6.qtdbus python3-requests`;
для работы ещё `qt6-image-formats-plugins` (картинки webp/avif) и `libnotify-bin`
(уведомления). В других местах с Python ≥ 3.11: `pip install requests PySide6-Essentials`.

## Правила, коротко

Полный список — [AGENTS.md](../../../AGENTS.md) (одна страница, по-английски).

* Ядро никогда не импортирует тулкит; фронтенды говорят с ним только через фьючерсы и события.
* Любое поведение — флаг в конфиге: новая опция идёт в `config.DEFAULTS` и оба примера
  конфига, с пояснением на языке каждого.
* Каждая строка интерфейса — и в `ru`, и в `en`.
* Документы для разработчиков — на двух языках, `docs/ru/dev/` и `docs/en/dev/`: поменял один —
  поменяй другой в том же коммите (тест сравнивает их скелеты). CHANGELOG — только по-английски.
* Каждая починка — с тестом; CHANGELOG и список возможностей не отстают от кода.
* Токен никогда не пишется в журнал и не уходит на другие серверы.
* Комментарии и сообщения коммитов — по-английски.
