## Четыре интерфейса

fedtail — это окно Qt (KDE, Windows), окно GTK (GNOME), терминал и веб-страница; ядро у них одно, и почти всё есть везде. Ниже — только то, что есть не везде, и почему. ✓ — есть, ◐ — частично, — — нет, · — там не нужно. Таблицу держит в честности тест: функция, которая появилась или пропала в одном интерфейсе, без строчки здесь не пройдёт.

### Окно, аккаунты, вход

| Что | Qt | GTK | Терминал | Веб | Почему |
|---|---|---|---|---|---|
| Вход на сервер | ✓ | ✓ | — | — | Входят в окне (Qt или GTK); терминал и веб открывают профиль, который уже вошёл, и подсказывают войти в окне. |
| Аккаунты: добавить, главный, выйти | ✓ | ✓ | — | — | Профили заводят и переключают в окне; терминал и веб работают с тем, с каким запущены (`--profile`). |
| Все аккаунты в одном окне | ✓ | ✓ | ◐ | ◐ | Сливаются ленты и в терминале, и в вебе (`ui.merge`), но переключателя в меню и пометки «получено через @…» у поста там нет. |
| Значок в трее | ✓ | ✓ | · | · | У терминала и вкладки браузера трея нет. |
| Шторка (Esc закрывает ленты) | ✓ | ✓ | · | · | В терминале и вебе Esc — шаг назад, закрывать нечего. |
| Ленты колонками | ✓ | ✓ | — | — | Одна лента за раз; колонки — только в окне. |
| Ростер и окно сообщений, как в QIP (`ui.layout = "split"`) | ✓ | ✓ | — | — | Раскладка двух окон есть только у Qt и GTK. |
| Ленты слева по группам | ✓ | ✓ | ◐ | ◐ | Веб и терминал показывают ленты одним списком — в том же порядке, но без заголовков групп и без сворачивания. |
| Порядок списков: выше, ниже | ✓ | ✓ | — | — | Двигать списки можно в окне; порядок общий (синхронизация), терминал и веб его соблюдают. |
| Объявления сервера | ✓ | ✓ | — | — | Плашка с объявлением есть только в окне. |

### Чтение

| Что | Qt | GTK | Терминал | Веб | Почему |
|---|---|---|---|---|---|
| Поиск в ленте: глубже, во всех лентах | ✓ | ✓ | ◐ | ◐ | Терминал и веб ищут в том, что на экране; в архиве и во всех лентах — только окно. |
| Поиск: к предыдущему, закрыть | ✓ | ✓ | ◐ | ✓ | В терминале Ctrl+F ищет только вперёд. |
| Шапка треда: сколько постов, все CW разом, подписка кнопкой | ✓ | ✓ | ◐ | ◐ | Подписаться на тред можно из меню ⋯ поста; счётчика и «открыть все CW» нет. |
| Вид ленты: беседами, только посты, только новое, «к новому» | ✓ | ✓ | ◐ | ✓ | Терминал показывает ленту постами по порядку; фильтр по картинкам и «только посты» — по `s`. |
| Голосовать в опросе | ✓ | ✓ | — | ✓ | Терминал показывает, что в посте опрос, но голосовать — в окне или в вебе. |
| Опрос: результаты, обновить, сколько человек | ✓ | ✓ | — | ◐ | Веб показывает голоса у вариантов, без кнопок «результаты» и «обновить». |
| Старые посты человека с его сервера | ✓ | ✓ | — | — | «▼ ещё раньше — с …» в профиле есть только в окне. |
| Профиль: счётчики, «с нами с», общие подписки, избранное, переезд | ✓ | ✓ | ◐ | ◐ | Терминал и веб показывают профиль строками, без этих подробностей шапки. |
| Сменить свои аватар и шапку | ✓ | ✓ | — | — | Имя, описание и поля правятся везде; картинки — только в окне. |
| Тег на свой профиль; убрать ленту тега | ✓ | ✓ | — | — | Подписка на тег и «в ленты» есть везде; «на мой профиль» и «убрать из лент» — в окне. |

### Картинки и видео

| Что | Qt | GTK | Терминал | Веб | Почему |
|---|---|---|---|---|---|
| Просмотр картинок: листать, 1:1, оригинал, сохранить | ✓ | ✓ | ◐ | ◐ | Терминал показывает картинку на весь экран (chafa, kitty) или своим экраном; веб — картинку в просмотрщике страницы и «открыть оригинал». Сохранить — в окне (в вебе — средствами браузера). |
| Видео и звук в самой программе | ✓ | ✓ | ◐ | ◐ | Терминал играет в mpv (окном или в самом терминале), веб — плеером браузера. |

| Что | Qt | GTK | Терминал | Веб | Почему |
|---|---|---|---|---|---|
| Предупреждение о картинке без описания | ✓ | ✓ | — | — | Перед отправкой спрашивает только окно. |

| Предпросмотр поста | ✓ | ✓ | — | — | Как пост будет выглядеть — только в окне. |
| Редактор: «выкинуть», другой язык, подсказка про #CamelCase | ✓ | ✓ | — | — | Черновик хранится везде; выкинуть с вопросом, ввести язык не из списка и подсказка доступности — в окне. |

### Сервер, настройки, справка, отладка

| Что | Qt | GTK | Терминал | Веб | Почему |
|---|---|---|---|---|---|
| «Что умеет сервер» — проверка возможностей | ✓ | ✓ | — | — | Состояние федерации есть везде; проверка двух десятков возможностей — вкладка окна. |
| Состояние федерации: скопировать, обновить, сбросить | ✓ | ✓ | ◐ | ◐ | Терминал и веб показывают состояние, без кнопок. |
| Что придерживать из уведомлений (правило сервера) | ✓ | ✓ | — | — | Придержанное видно везде; само правило меняют в окне. |
| Режим arts: пометка в меню | ✓ | ✓ | — | — | `ui.arts_mode` действует везде; напоминание о нём — в меню окна. |
| Окно настроек: поиск, перезапуск, «открыть файл» | ✓ | ✓ | ◐ | ◐ | Терминал и веб правят тот же config.toml формой по главам; поиска, кнопки перезапуска и «открыть файл» там нет. |
| Темы: попробовать, папка тем | ✓ | ✓ | ◐ | — | У терминала свои темы (`tui.theme`); веб тем пока не знает. |
| Открыть конфиг и папку данных | ✓ | ✓ | — | · | Терминал пишет пути (≡ → «Отладка»); у веба нет доступа к файлам машины. |
| Справка: поиск, назад, вперёд | ✓ | ✓ | ◐ | ◐ | Справка открывается везде, ссылки между страницами работают; поиска и истории нет. |
| «О программе»: скопировать сведения | ✓ | ✓ | — | — | Сведения те же; кнопки «скопировать» нет — текст можно выделить. |
| Уведомления рабочего стола и их проверка | ✓ | ✓ | — | ◐ | Терминал сообщает звуком (`tui.sound`); веб — уведомлениями браузера, если разрешить. |
| Отладка: журнал, отчёт, звук, стеки | ✓ | ✓ | ✓ | — | Веб-страница — гость в браузере: отчёт собирают в окне, терминале или `fedtail --bug-report`. |
| Отладка памяти: перепись, снимок, трассировка, отдать память | ✓ | ✓ | — | — | Охота на утечки — в окне, где они и случаются. |
| Подсказки при наведении и «Что это?» | ✓ | ✓ | · | ◐ | В терминале наводить нечем — подсказки там в строке клавиш внизу; в вебе подсказки у части кнопок. |
