## Четыре интерфейса

fedtail — это окно Qt (KDE, Windows), окно GTK (GNOME), терминал и веб-страница; ядро у них одно, и почти всё есть везде. Ниже — только то, что есть не везде, и почему. ✓ — есть, ◐ — частично, — — нет, · — там не нужно. Таблицу держит в честности тест: функция, которая появилась или пропала в одном интерфейсе, без строчки здесь не пройдёт.

### Окно, аккаунты, вход

| Что | Qt | GTK | Терминал | Веб | Почему |
|---|---|---|---|---|---|
| Вход на сервер | ✓ | ✓ | — | — | Входят в окне (Qt или GTK); терминал и веб открывают профиль, который уже вошёл, и подсказывают войти в окне. |
| Аккаунты: добавить, главный, выйти | ✓ | ✓ | — | — | Профили заводят и переключают в окне; терминал и веб работают с тем, с каким запущены (`--profile`). |
| Все аккаунты в одном окне | ✓ | ✓ | ✓ | ◐ | Терминал и веб сливают ленты (`ui.merge`) и помечают чужие посты «получено через @…»; переключатель в меню — у окон и терминала, у веба пока нет. |
| Значок в трее | ✓ | ✓ | · | · | У терминала и вкладки браузера трея нет. |
| Шторка (Esc закрывает ленты) | ✓ | ✓ | · | · | В терминале и вебе Esc — шаг назад, закрывать нечего. |
| Ленты колонками | ✓ | ✓ | — | — | Одна лента за раз; колонки — только в окне. |
| Ростер и окно сообщений, как в QIP (`ui.layout = "split"`) | ✓ | ✓ | — | — | Раскладка двух окон есть только у Qt и GTK. |

### Чтение

| Что | Qt | GTK | Терминал | Веб | Почему |
|---|---|---|---|---|---|
| Шапка треда: сколько постов, все CW разом, подписка кнопкой | ✓ | ✓ | ✓ | ◐ | Шапка треда везде; веб, отписываясь от треда, не пишет «больше не придёт». |
| Старые посты человека с его сервера | ✓ | ✓ | ◐ | ◐ | Подтягиваются страницами по кнопке «ещё» внизу, без живого счётчика «n из N». |

### Картинки и видео

| Что | Qt | GTK | Терминал | Веб | Почему |
|---|---|---|---|---|---|
| Просмотр картинок: листать, 1:1, оригинал, сохранить | ✓ | ✓ | ◐ | ◐ | Терминал показывает картинку во весь экран (chafa, kitty) и сохраняет оригинал (`s`); веб — свой просмотрщик с «сохранить» и 1:1. Слова окна о форматах Qt и «оригинал грузится» им не нужны. |
| Видео и звук в самой программе | ✓ | ✓ | ◐ | ◐ | Терминал играет в mpv (окном или в самом терминале), веб — плеером браузера. |

### Редактор

| Что | Qt | GTK | Терминал | Веб | Почему |
|---|---|---|---|---|---|
| Фокус картинки для превью | ✓ | ✓ | — | ✓ | В терминале щёлкнуть по картинке нечем; фокус остаётся по центру. |

### Сервер, настройки, справка, отладка

| Что | Qt | GTK | Терминал | Веб | Почему |
|---|---|---|---|---|---|
| Окно настроек: поиск, перезапуск, «открыть файл» | ✓ | ✓ | ◐ | ◐ | Терминал и веб правят тот же config.toml формой по главам; поиска, кнопки перезапуска и «открыть файл» там нет. |
| Темы: попробовать, папка тем | ✓ | ✓ | ◐ | — | У терминала свои темы (`tui.theme`); веб тем пока не знает. |
| Открыть конфиг и папку данных | ✓ | ✓ | ✓ | · | Терминал открывает конфиг в $EDITOR и копирует пути (≡ → «Отладка»); у веба нет доступа к файлам машины. |
| Справка: поиск, назад, вперёд | ✓ | ✓ | ◐ | ◐ | Справка с поиском есть везде; истории «назад / вперёд» у страниц терминала и веба нет. |
| Уведомления рабочего стола и их проверка | ✓ | ✓ | ✓ | ◐ | Терминал — через notify-send или кодом самого терминала (kitty, WezTerm, foot…); веб — уведомлениями браузера, если разрешить, без проверки в меню. |
| Отладка: журнал, отчёт, звук, стеки | ✓ | ✓ | ✓ | — | Веб-страница — гость в браузере: отчёт собирают в окне, терминале или `fedtail --bug-report`. |
| Отладка памяти: перепись, снимок, трассировка, отдать память | ✓ | ✓ | ✓ | — | Охота на утечки — в окнах и терминале; веб-страница — гость в браузере. |
| Подсказки при наведении и «Что это?» | ✓ | ✓ | · | ◐ | В терминале наводить нечем — подсказки там в строке клавиш внизу; в вебе подсказки у части кнопок. |
