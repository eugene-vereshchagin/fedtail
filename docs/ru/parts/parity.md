## Пять интерфейсов

fedtail — это окно Qt (KDE, Windows), окно GTK (GNOME), терминал, веб-страница и приложение для Android; ядро у них одно. Ниже — только то, что есть не везде, и почему. ✓ — есть, ◐ — частично, — — нет, · — там не нужно. Таблицу держит в честности тест: функция, которая появилась или пропала в одном из компьютерных интерфейсов, без строчки здесь не пройдёт; у телефона свои экраны и слова — его столбец сверен по коду руками, а всё, чего на телефоне пока нет, — в следующей главе.

### Окно, аккаунты, вход

| Что | Qt | GTK | Терминал | Веб | Android | Почему |
|---|---|---|---|---|---|---|
| Вход на сервер | ✓ | ✓ | ◐ | ◐ | ✓ | Терминал и веб входят так же: адрес сервера, страница входа в браузере, код. Сам веб для профиля без входа не запускается — входят со страницы другого профиля. |
| Аккаунты: добавить, главный, выйти | ✓ | ✓ | ✓ | ✓ | — | Android: один аккаунт |
| Все аккаунты в одном окне | ✓ | ✓ | ✓ | ✓ | — | Android: один аккаунт |
| Значок в трее | ✓ | ✓ | · | · | · | У терминала и вкладки браузера трея нет. Android: трея у телефона нет |
| Шторка (Esc закрывает ленты) | ✓ | ✓ | · | · | · | В терминале и вебе Esc — шаг назад, закрывать нечего. Android: Esc у телефона нет |
| Ленты колонками | ✓ | ✓ | · | · | ✓ | Одна лента за раз; колонки — в окне и на планшете (обзор, лента, тред рядом). |
| Ростер и окно сообщений, как в QIP (`ui.layout = "split"`) | ✓ | ✓ | · | · | · | Раскладка двух окон есть только у Qt и GTK. Android: раскладка окон компьютера |
| Порядок списков: выше, ниже | ✓ | ✓ | ✓ | ✓ | ◐ | Двигать списки можно в окне; порядок общий (синхронизация), терминал и веб его соблюдают. Android: порядок лент — плитками |

### Чтение

| Что | Qt | GTK | Терминал | Веб | Android | Почему |
|---|---|---|---|---|---|---|
| Поиск в ленте: глубже, во всех лентах | ✓ | ✓ | ✓ | ✓ | — | Терминал и веб ищут в том, что на экране; в архиве и во всех лентах — только окно. Android: поиска в ленте нет |
| Поиск: к предыдущему, закрыть | ✓ | ✓ | ✓ | ✓ | — | В терминале Ctrl+F ищет только вперёд. Android: поиска в ленте нет |
| Шапка треда: сколько постов, все CW разом, подписка кнопкой | ✓ | ✓ | ✓ | ✓ | ◐ | Android: тред есть, подписка — в меню ⋯; шапки нет |
| Вид ленты: беседами, только посты, только новое, «к новому» | ✓ | ✓ | ✓ | ✓ | — | Терминал показывает ленту постами по порядку; фильтр по картинкам и «только посты» — по `s`. Android: переключателей вида ленты нет |
| Опрос: результаты, обновить, сколько человек | ✓ | ✓ | ✓ | ✓ | ◐ | Веб показывает голоса у вариантов, без кнопок «результаты» и «обновить». Android: итоги текстом |
| Старые посты человека с его сервера | ✓ | ✓ | ◐ | ◐ | — | Подтягиваются страницами по кнопке «ещё» внизу, без живого счётчика «n из N». Android: профиль показывает первую страницу постов |
| Профиль: счётчики, «с нами с», общие подписки, избранное, переезд | ✓ | ✓ | ✓ | ✓ | ◐ | Терминал и веб показывают профиль строками, без этих подробностей шапки. Android: счётчики и «с какого времени»; общих подписок, рекомендаций, переезда нет |

### Картинки и видео

| Что | Qt | GTK | Терминал | Веб | Android | Почему |
|---|---|---|---|---|---|---|
| Просмотр картинок: листать, 1:1, оригинал, сохранить | ✓ | ✓ | ◐ | ◐ | ◐ | Терминал показывает картинку во весь экран (chafa, kitty) и сохраняет оригинал (`s`); веб — свой просмотрщик с «сохранить» и 1:1. Слова окна о форматах Qt и «оригинал грузится» им не нужны. Android: листать и увеличивать можно; оригинала и «сохранить» нет |
| Видео и звук в самой программе | ✓ | ✓ | ◐ | ◐ | ◐ | Терминал играет в mpv (окном или в самом терминале), веб — плеером браузера. Android: видео и звук — в браузере |

### Редактор

| Что | Qt | GTK | Терминал | Веб | Android | Почему |
|---|---|---|---|---|---|---|
| Фокус картинки для превью | ✓ | ✓ | · | ✓ | — | В терминале щёлкнуть по картинке нечем; фокус остаётся по центру. Android: фокуса картинки на телефоне нет |
| Предпросмотр поста | ✓ | ✓ | ✓ | ✓ | — | Как пост будет выглядеть — только в окне. Android: пока нет |
| Редактор: «выкинуть», другой язык, подсказка про #CamelCase | ✓ | ✓ | ✓ | ✓ | ◐ | Черновик хранится везде; выкинуть с вопросом, ввести язык не из списка и подсказка доступности — в окне. Android: отменить — «назад»; «другого языка» и подсказки #CamelCase нет |
| Проверка орфографии в окне поста | ✓ | ✓ | ◐ | ◐ | ◐ | Окна подчёркивают ошибки и правят их правым кликом; терминал — списком по F7 (подчеркнуть в поле ввода нечем); веб — встроенной проверкой браузера на языке поста. Android: проверяет клавиатура телефона |

### Сервер, настройки, справка, отладка

| Что | Qt | GTK | Терминал | Веб | Android | Почему |
|---|---|---|---|---|---|---|
| «Что умеет сервер» — проверка возможностей | ✓ | ✓ | ✓ | ✓ | ◐ | Состояние федерации есть везде; проверка двух десятков возможностей — вкладка окна. Android: сервер смотрит самопроверка |
| Режим arts: пометка в меню | ✓ | ✓ | ✓ | ✓ | ◐ | `ui.arts_mode` действует везде; напоминание о нём — в меню окна. Android: настройкой, без отметки в меню |
| Окно настроек: поиск, перезапуск, «открыть файл» | ✓ | ✓ | ◐ | ◐ | ✓ | Терминал и веб правят тот же config.toml формой по главам, с поиском и «Открыть файл» (терминал — в $EDITOR, веб копирует путь). Перезапуска нет: их перезапускают, как запускали; «файл изменили снаружи» не нужно — место перечитывает файл при каждом открытии. |
| Темы: попробовать, папка тем | ✓ | ✓ | ◐ | ◐ | — | У терминала свои темы (`tui.theme`). Веб берёт из тем окон цвета и шрифт и пробует их из меню ≡, но папку тем не открывает: страница — гость в браузере. Android: одна тема, светлая и тёмная по телефону |
| Открыть конфиг и папку данных | ✓ | ✓ | ✓ | · | ◐ | Терминал открывает конфиг в $EDITOR и копирует пути (≡ → «Отладка»); у веба нет доступа к файлам машины. Android: конфиг правится в приложении; папки данных нет |
| Справка: поиск, назад, вперёд | ✓ | ✓ | ✓ | ✓ | ◐ | Android: справка и поиск по ней, назад — кнопкой «назад»; вперёд нет |
| «О программе»: скопировать сведения | ✓ | ✓ | ✓ | ✓ | ◐ | Сведения те же; кнопки «скопировать» нет — текст можно выделить. Android: сведения — в самопроверке, «Поделиться» |
| Уведомления рабочего стола и их проверка | ✓ | ✓ | ✓ | ✓ | — | Терминал — через notify-send или кодом самого терминала (kitty, WezTerm, foot…); веб — уведомлениями браузера, если разрешить. Android: системных уведомлений пока нет |
| Отладка: журнал, отчёт, звук, стеки | ✓ | ✓ | ✓ | · | ◐ | Веб-страница — гость в браузере: отчёт собирают в окне, терминале или `fedtail --bug-report`. Android: самопроверка и её отчёт |
| Отладка памяти: перепись, снимок, трассировка, отдать память | ✓ | ✓ | ✓ | · | · | Охота на утечки — в окнах и терминале; веб-страница — гость в браузере. Android: инструмент для компьютера |
| Подсказки при наведении и «Что это?» | ✓ | ✓ | · | ◐ | · | В терминале наводить нечем — подсказки там в строке клавиш внизу. В вебе подсказки у кнопок, лент и пунктов меню; режима «Что это?» нет (браузер и так показывает подсказку при наведении), и нет подсказок у того, чего у веба нет (ширина колонки, размер редактора, трассировка). Android: наводить мышь нечем |
