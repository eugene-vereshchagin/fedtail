## Пять интерфейсов

fedtail — это окно Qt (KDE, Windows), окно GTK (GNOME), терминал, веб-страница и приложение для Android; ядро у них одно. Ниже — только то, что есть не везде, и почему. ✓ — есть, ◐ — частично, — — нет, · — там не нужно. Таблицу держит в честности тест: функция, которая появилась или пропала в одном из компьютерных интерфейсов, без строчки здесь не пройдёт; у телефона свои экраны и слова — его столбец сверен по коду руками, а всё, чего на телефоне пока нет, — в следующей главе.

### Окно, аккаунты, вход

| Что | Qt | GTK | Терминал | Веб | Android | Почему |
|---|---|---|---|---|---|---|
| Закреплённые вкладки | ✓ | ✓ | · | · | · | ui.pin_tabs: правый щелчок по вкладке треда или профиля. В терминале, вебе и на телефоне таких вкладок нет — тред и профиль открываются поверх ленты и уходят «назад». Android: Вкладок нет: экраны идут стопкой, «назад» — предыдущий. |
| Значок в трее | ✓ | ✓ | · | · | · | У терминала и вкладки браузера трея нет. Android: трея у телефона нет |
| Шторка (Esc закрывает ленты) | ✓ | ✓ | · | · | · | В терминале и вебе Esc — шаг назад, закрывать нечего; шторка там — при запуске (`window.start_lane = "none"`), Enter открывает прошлую ленту. Android: Esc у телефона нет |
| Ленты колонками | ✓ | ✓ | · | ✓ | ✓ | Терминал — одна лента за раз. Веб — колонки по ❯, как в окнах (на ширине телефона — одна лента); телефон — на планшете (обзор, лента, тред рядом). |
| Ростер и окно сообщений, как в QIP (`window.layout = "split"`) | ✓ | ✓ | · | · | · | Раскладка двух окон есть только у Qt и GTK. Android: раскладка окон компьютера |
| Плитки лент на заставке | ✓ | ✓ | ◐ | ✓ | ✓ | `window.tiles`: на заставке (все ленты закрыты) — ленты плитками по секциям боковой панели, список лент слева отходит; на телефоне это его обзор (`phone.overview`). Терминал — строки текста: его шторка (общие слова, `common/sidebar.curtain`) плиток не рисует, его боковая панель и есть список. |

### Чтение

| Что | Qt | GTK | Терминал | Веб | Android | Почему |
|---|---|---|---|---|---|---|
| Подсказка к числу символов | ✓ | ✓ | · | ✓ | ✓ | Число символов поста (`card.char_count`) показывают все; подсказку «Символов в тексте поста» под мышкой — окна и веб. В терминале и на телефоне мыши нет: число стоит само по себе. |
| Эмодзи серверов картинками | ✓ | ✓ | · | ✓ | ✓ | Окна на Qt и GTK и веб рисуют :blobcat: картинкой — в постах, в именах, в бусте, в цитате и в Активности. Терминал — текстом: картинка в строку текста не встаёт. |
| Инструменты над постом под мышкой | ✓ | ✓ | · | ✓ | · | ui.hover_tools: в окнах Qt и GTK и на веб-странице у поста под мышкой справа вверху — открыть в браузере, копировать ссылку, перевести, цитировать, следить за тредом, заглушить его, прочитано до сюда, а у своего — изменить и удалить; в меню ⋯ их там уже нет. В терминале мышки нет — всё в меню поста. Android: у телефона нет мышки: всё в меню ⋯ карточки |
| Меню поста подменю | ✓ | ✓ | ◐ | ✓ | — | ui.menu_groups: в окнах Qt и GTK и на веб-странице меню ⋯ — частое наверху и подменю «Автор @…», «Тред», «Ещё». В терминале меню поста одним списком (его слова в общем коде, подменю он пока не рисует). Android: меню карточки на телефоне пока плоское |
| Старые посты человека с его сервера | ✓ | ✓ | ◐ | ✓ | ✓ | Веб — как окна: адреса страницы сразу, посты по четыре, на кнопке живой счётчик «n из N». Терминал подтягивает страницу целиком по кнопке «ещё» и потом говорит, сколько пришло, — без живого счётчика. |

### Картинки и видео

| Что | Qt | GTK | Терминал | Веб | Android | Почему |
|---|---|---|---|---|---|---|
| Ссылка на видео- и аудиофайл — в свой плеер | ✓ | ✓ | ✓ | · | ✓ | Ссылка в тексте поста на .mp4, .webm, .mp3, .opus… (так оставляет её сервер, не принявший большое вложение) играет в том же плеере, что и вложения: в окнах Qt и GTK — поверх окна, в терминале — mpv, на телефоне — его плеер (`media.links_in_player`). Веб-странице не нужно: браузер играет такой файл сам. |
| Просмотр картинок: листать, 1:1, оригинал, сохранить | ✓ | ✓ | ◐ | ◐ | ✓ | Терминал показывает картинку во весь экран (chafa, kitty) и сохраняет оригинал (`s`); веб — свой просмотрщик с «сохранить» и 1:1. Слова окна о форматах Qt и «оригинал грузится» им не нужны. |
| Видео и звук в самой программе | ✓ | ✓ | ◐ | ◐ | ✓ | Терминал играет в mpv (окном или в самом терминале), веб — плеером браузера. |

### Редактор

| Что | Qt | GTK | Терминал | Веб | Android | Почему |
|---|---|---|---|---|---|---|
| Фокус картинки для превью | ✓ | ✓ | · | ✓ | ✓ | В терминале щёлкнуть по картинке нечем; фокус остаётся по центру. |
| Кнопки разметки в редакторе | ✓ | ✓ | ◐ | ✓ | ✓ | post.format_bar: жирный, курсив, зачёркнутый, код, ссылка, цитата, список — метки Markdown вокруг выделенного. В терминале — только кнопками мышью: Ctrl+B/I/K там у поля текста свои (Ctrl+I — это Tab). |
| Проверка орфографии в окне поста | ✓ | ✓ | ◐ | ◐ | ◐ | Окна подчёркивают ошибки и правят их правым кликом; терминал — списком по F7 (подчеркнуть в поле ввода нечем); веб — встроенной проверкой браузера на языке поста. Android: проверяет клавиатура телефона |

### Сервер, настройки, справка, отладка

| Что | Qt | GTK | Терминал | Веб | Android | Почему |
|---|---|---|---|---|---|---|
| Папка синхронизации — через системный выбор папки | · | · | · | · | ✓ | На компьютере программе доступна любая папка пользователя: путь пишут в поле. Android 11+ пускает приложение в общую папку (Syncthing) только через свой выбор папки — там рядом с полем кнопка «Выбрать папку». |
| Окно настроек: поиск, перезапуск, «открыть файл» | ✓ | ✓ | ◐ | ◐ | ✓ | Терминал и веб правят тот же config.toml формой по главам, с поиском и «Открыть файл» (терминал — в $EDITOR, веб копирует путь). Перезапуска нет: их перезапускают, как запускали; «файл изменили снаружи» не нужно — место перечитывает файл при каждом открытии. |
| Темы: попробовать | ✓ | ✓ | ◐ | ◐ | ◐ | У терминала свои темы (`tui.theme`). Веб берёт из тем окон цвета и шрифт и пробует их из меню ≡, но папку тем не открывает: страница — гость в браузере. Android: цвета, шрифты и картинки тем окон, «примерить» — в меню; папка тем закрыта, свои темы — zip-файлом (≡ → «Добавить тему из файла…») |
| Тема одним файлом: выгрузить и загрузить | ✓ | — | — | · | ✓ | GTK пока без этих пунктов: папка тем там открыта, а архив делает и берёт командная строка (`--theme-export`, `--theme-import`) — она же для терминала. Веб — гость в браузере: класть файлы в папку тем ему не положено. |
| Уведомления рабочего стола и их проверка | ✓ | ✓ | ✓ | ✓ | ◐ | Терминал — через notify-send или кодом самого терминала (kitty, WezTerm, foot…); веб — уведомлениями браузера, если разрешить. Android: Уведомления — в шторку телефона, но проверочного («Отладка → Проверить уведомление») нет: Android сам показывает, разрешены ли они |
| Отладка: полный слепок в архив, журнал, звук | ✓ | ✓ | ✓ | · | ◐ | Веб-страница — гость в браузере: отчёт собирают в окне, терминале или `fedtail --bug-report`. Android: Отчёт — ⋮ → «Отправить отчёт» (журнал внутри); звука на телефоне нет — проверять нечего |
| Подсказки при наведении и «Что это?» | ✓ | ✓ | · | ◐ | · | В терминале наводить нечем — подсказки там в строке клавиш внизу. В вебе подсказки у кнопок, лент и пунктов меню; режима «Что это?» нет (браузер и так показывает подсказку при наведении), и нет подсказок у того, чего у веба нет (размер редактора, трассировка). Android: наводить мышь нечем |
