## Android: что на телефоне есть и чего пока нет

Возможности из списка выше, которых в приложении для Android нет или есть не целиком (◐ — частично, — — нет, · — телефону не нужно). Остальное на телефоне есть.

### Ленты

| Что | Android | Почему |
|---|---|---|
| Кто в списке; свой порядок списков | ◐ | порядок лент — плитками; «кто в списке» нет |
| Лента хэштега, подписка на теги | ◐ | ленты тегов читаются; подписаться на тег, открыть тег из поста — нет |
| Пустая живая лента объясняет, почему пуста | ◐ | пустая лента говорит «пока пусто», без причины |
| Фильтр ленты по медиа и бустам | — | фильтра ленты по медиа нет |
| Всё / Только посты / Новое; Лентой / Беседами | — | переключателей «Все / Только посты / Разговоры» нет |
| Поиск по ленте | — | поиск в переключателе — по лентам, не по постам |
| Поиск во всех лентах сразу | — | поиска по всем лентам нет |
| Лента из нескольких тегов | ◐ | читаются; собрать — только на компьютере или в конфиге |
| Раскладка как в аське: ростер и окно сообщений | · | на телефоне не нужно |
