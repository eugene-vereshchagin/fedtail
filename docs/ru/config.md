# Настройки fedtail

[English](/docs/en/config.md)

Справочник по всем ключам конфига, таблицами по главам. **Файл собирается сам** из
`fedtail/data/config.example.ru.toml` командой `python3 tools/docs_build.py` — правь
пояснения там, а не здесь (тест проверяет, что этот файл не отстал).

Что за возможность стоит за ключом и как это у других клиентов —
[список возможностей](/docs/ru/features.md).

## Как устроен конфиг

Здесь все настройки — со значениями по умолчанию и пояснениями. Поменяй, что нужно, и перезапусти fedtail. Или открой ≡ → Настройки: окно правит этот же файл — ровно ту строку, что ты поменял, комментарии и остальное не трогает (прежний файл — config.toml.bak). Сама программа его не переписывает.

Значение, записанное здесь, остаётся твоим, даже если в новой версии умолчание изменится. Хочешь всегда умолчание программы — закомментируй строку (# в начале) или удали её.

Новая версия принесла новые настройки — `python3 -m fedtail --update-config` допишет их в нужные главы (старый файл сохранится как config.toml.bak). Пересобрать файл заново по главам, с твоими значениями — `python3 -m fedtail --rebuild-config`. Полный справочник текущей версии всегда лежит рядом: config.example.ru.toml (и config.example.en.toml — то же по-английски).

Где лежит: ~/.config/fedtail/<профиль>/config.toml  (без --profile — главный профиль, ★)

## Ключи запуска

| Ключ | Что делает |
|---|---|
| `-p, --profile ИМЯ` | профиль = аккаунт со своим конфигом и данными (без него — главный) |
| `-c, --config ФАЙЛ` | другой конфиг вместо конфига профиля |
| `-d, --data ПАПКА` | другая папка данных вместо папки профиля |
| `--ui qt\|tui\|web` | окно, терминал или браузер (на один запуск; постоянно — ui.frontend) |
| `--layout single\|split` | раскладка окна на один запуск (постоянно — ui.layout); columns — single с лентами колонками (ui.open_columns) |
| `--theme ИМЯ` | тема на один запуск (постоянно — ui.theme) |
| `--profiles` | какие профили есть — и выйти |
| `--update-config` | дописать в этот файл новые настройки с пояснениями — и выйти |
| `--rebuild-config` | пересобрать этот файл по главам, с твоими значениями — и выйти |
| `--lanes-to-config` | выписать сюда ленты набора (lanes.preset) как [[lanes.custom]] — и выйти |
| `--install-desktop` | добавить fedtail (этот профиль) в меню с иконкой — и выйти |
| `--debug` | подробный журнал на этот запуск, и он же — в терминал |
| `--bug-report` | собрать логи и сведения о системе в архив для разбора — и выйти |
| `-V, --version` | версия — и выйти |
| `КОМАНДА` | работа в терминале без окна: lanes, show, tail, read, post (fedtail КОМАНДА -h — подробно про каждую) |

## 1. Вид и окно

### Как выглядит

| `ui.faces` | `true` | При layout = "split" — лица, как в QIP: над постами ленты — автор того, что под курсором, с кнопками (подписка, списки, личное сообщение, профиль); у строки ввода — тот, кому пишу. |
| `ui.dock_commands` | `true` | При layout = "split" — строка ввода внизу понимает и команды командной строки ("#a3f текст", "! #a3f", "S #a3f", "?" — Enter выполняет), а сама командная строка спрятана (Ctrl+L её покажет). false — строка ввода только пишет. |

| `ui.icons` | `"theme"` | Картинки на кнопках и у лент: "theme" — как решила тема (system и debug — значки рабочего стола, terminal и bnw — без картинок, остальные — свой набор из папки темы); "desktop" — значки рабочего стола (Breeze…); "own" — набор темы, а мессенджерные картинки (строка ввода, ростер, цветок у человека) — только в раскладке split; "additional" — набор темы, и мессенджерные картинки везде, где есть их кнопки (окно поста, профиль); "words" — без картинок, слова и знаки ≡ ↔ ❯. |
| `ui.columns` | `[]` | Какие ленты стоят колонками, слева направо, пока ты их не поменял в окне (клик по ленте слева добавляет колонку, ✕ на колонке убирает, ‹ › двигают; это запоминается). Имена — как в lanes.enabled; "list:Друзья" — список по названию. [] — Лента, Ответы мне и Активность. |

| `ui.actions` | `"both"` | Кнопки под постом: "both" — иконка и подпись, "icons" — только иконки (подписи всплывают при наведении), "text" — только подписи. |
| `ui.expand_cw` | `true` | Тексты и картинки под предупреждением (CW) сразу развёрнуты. false — свёрнуты, разворачиваются кнопкой «показать». |

### Окно, клавиши, запуск

| Ключ | По умолчанию | Что делает |
|---|---|---|
| `ui.tray` | `true` | Значок в трее (qt, gtk). false — никакого значка: уведомления тогда только через рабочий стол (notify-send), крестик закрывает программу, Esc с ui.esc = "tray" сворачивает. |
| `ui.close_to_tray` | `true` | Крестик прячет окно в трей, а не закрывает программу. |
| `ui.esc` | `"curtain"` | Esc закрывает то, что сверху (картинку, поиск), а последний Esc:<br>"curtain" — закрывает все ленты шторкой: окно остаётся, слева счётчики, справа пусто; ничего не отмечается прочитанным — утром откроешь, а новое накопилось;<br>"tray" — сразу убирает окно в трей (без трея — сворачивает);<br>"off" — ничего не делает. |
| `ui.start_lane` | `"none"` | Что открыто при запуске:<br>"none" — ничего: все ленты за шторкой, слева счётчики (Enter откроет прошлую);<br>"last" — лента, открытая в прошлый раз;<br>имя ленты — всегда она: "home", "replies", "subs"… (как в [lanes]). |
| `ui.compose` | `"inline"` | Где писать пост: "inline" — панелью внутри главного окна (раскладка клавиатуры не сбрасывается: KDE помнит её для каждого окна, и новое окно может открыться с другой); "window" — отдельным окном, как раньше. |
| `ui.compose_size` | `0` | Размер панели поста — в процентах от главного окна (и следом за ним, когда окно меняет размер): 50, 80, 100… 0 — как было, не больше 820 × 540. Кнопка ⤡ в панели переключает между обычным и большим (90 %) и запоминает выбор. |
| `ui.command_line` | `true` | Командная строка как на Point внизу окна (Ctrl+L покажет её, даже если false). |
| `ui.whats_this` | `false` | Режим «Что это?» с самого запуска: наведи мышь на кнопку — подробная подсказка, что она делает, какой ключ конфига её меняет и где об этом в справке. На время включается и выключается в меню ≡ → «Что это?». Горячей клавиши нет нарочно (F1 рядом с Esc). |

### Картинки и ссылки

| Ключ | По умолчанию | Что делает |
|---|---|---|
| `ui.image_height` | `360` | Высота одиночной картинки в ленте, пикселей (несколько картинок — плиткой поменьше). |
| `ui.image_viewer` | `"internal"` | Клик по картинке: "internal" — свой просмотрщик (← → листать, Esc закрыть), "browser" — открыть в браузере. |
| `ui.video_player` | `"internal"` | Видео и аудио: "internal" — прямо в окне (видео — поверх окна: пробел — пауза, ← → — перемотка, M — звук, O — в браузер, Esc — закрыть; аудио — плеер в карточке), "browser" — открывать в браузере. Нужен QtMultimedia (Debian: python3-pyside6.qtmultimedia python3-pyside6.qtmultimediawidgets); без него — браузер. |
| `ui.video_decode` | `"software"` | Чем декодировать видео: "software" — процессором (видео в федиверсе маленькие, ему легко), "hardware" — видеокартой, как решит Qt. | Ключ | По умолчанию | Что делает |
|---|---|---|

| `poll.stream_gap_seconds` | `10` | Живой поток будит опрос, как только что-то пришло, — но не чаще раза в столько секунд: на оживлённом сервере события идут по многу раз в минуту, а каждый опрос — десяток запросов и немного процессора. | `tui.video` | `"auto"` | Видео и гифки (v на посте с видео, Enter на нём среди картинок) играет mpv: "auto" — в своём окне, если есть рабочий стол, иначе прямо в терминале (по ssh: sixel, kitty или цветным текстом); "window" — всегда окно; "terminal" — всегда в терминале; "browser" — открыть в браузере. Нет mpv — браузер, и об этом скажет. |

## 14. В браузере

`fedtail --ui web` (или ui.frontend = "web"): fedtail во вкладке браузера. При запуске печатает ссылку с ключом (и открывает её); ключ лежит в папке данных профиля, web.key — удали файл, и будет новый (старые ссылки перестанут работать).

### `[web]`

| Ключ | По умолчанию | Что делает |
|---|---|---|
| `web.host` | `"127.0.0.1"` | На каком адресе ждать. "127.0.0.1" — только с этого компьютера; "0.0.0.0" — и из домашней сети (с телефона: одноразовая ссылка, которую fedtail печатает при запуске, с адресом компьютера вместо 127.0.0.1; действует 15 минут). Там всё идёт без шифрования, так что только для своей сети; снаружи — через VPN или прокси с TLS. |
| `web.port` | `8765` | Порт. |
| `web.open_browser` | `true` | Открыть браузер при запуске. |

## 15. На телефоне и планшете

Приложение для Android (папка android/ в репозитории). Конфиг там — этот же файл: в приложении ⋮ → «Настройки» (каждая опция с пояснением) или «Конфиг» (сам файл). На компьютере эти настройки ничего не делают.

### `[phone]`

| Ключ | По умолчанию | Что делает |
|---|---|---|
| `phone.overview` | `"tiles"` | Обзор лент — домашний экран: "tiles" — плитками по четыре в ряд (счётчик и название); "list" — списком, строка на ленту, с первым непрочитанным постом. |
| `phone.layout` | `"auto"` | Сколько колонок: "auto" — по ширине экрана (телефон — одна, телефон боком и узкий планшет — ленты и лента, широкий планшет — ленты, лента и тред рядом); "one", "two", "three" — всегда столько, если влезает. |
| `phone.push` | `"auto"` | Уведомления сразу, при закрытом приложении: "auto" — через UnifiedPush, если на телефоне есть его дистрибьютор (ntfy, Sunup, NextPush…): сервер пушит туда, приложение просыпается и спрашивает; без него или "off" — раз в 15 минут (чаще Android не даёт). |
