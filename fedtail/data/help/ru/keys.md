# Клавиши

Все сочетания клавиш одной таблицей.

## Окно

| Клавиша | Что делает |
|---|---|
| `Ctrl+N` | новый пост |
| `Ctrl+Enter` | отправить |
| `Ctrl+K` | найти людей, теги, посты |
| `Ctrl+F`, `F3`, `Shift+F3` | найти в ленте, треде или профиле |
| `Ctrl+L` | командная строка |
| `F5` | обновить |
| `Alt+1…9` | лента по номеру (`window.number_keys`: и Ctrl+1…9) |
| `Ctrl+W` | закрыть вкладку |
| `Esc` | закрыть то, что сверху; последний — шторка |
| `Ctrl+Q` | выход (крестик только прячет в трей) |

У справки и «Что это?» клавиш нет нарочно — только меню ≡: F1 рядом с Esc, промахнуться легко.

## Лента и тред

| Клавиша | Что делает |
|---|---|
| `j` / `k` | следующий / предыдущий пост |
| `r` | ответить |
| `f` | лайк |
| `b` | буст |
| `m` | в закладки |
| `o`, `Enter` | открыть тред |
| `]` / `[` | в треде: следующий / предыдущий комментарий верхнего уровня |
| `-` | в треде: свернуть ветку (и из глубокого ответа — всю ветку его верхнего комментария), ещё раз — развернуть (окно) |

Выключить эти буквы — `window.post_keys = false`.

## Просмотрщик и плеер

| Клавиша | Что делает |
|---|---|
| `←` `→` | листать картинки; в видео — перемотка |
| `PgUp` `PgDn` | следующее / предыдущее видео в посте |
| пробел | пауза |
| `M` | звук |
| `S` | сохранить |
| `O` | открыть в браузере |
| `Esc` | закрыть |
