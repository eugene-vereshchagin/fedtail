# Командная строка

Как на Point: Ctrl+L и команды.

## Команды

| Команда | Что делает |
|---|---|
| `#a3f` | открыть пост |
| `#a3f текст` | ответить на пост |
| `#a3f/2 текст` | ответить на коммент /2 его треда |
| `#a3f @кто текст` | позвать человека в тред |
| `S #a3f` / `U #a3f` | подписаться на тред / отписаться |
| `S @ник` / `U @ник` | подписаться на человека / отписаться |
| `! #a3f` | продвинуть (буст) |
| `~ #a3f` | в закладки |
| `D #a3f` | удалить свой пост (спросит) |
| `@ник` | открыть профиль |
| `@ник текст` | личное сообщение |
| просто текст | новый пост |
| `?` | список команд |

Пока печатаешь, справа написано, что сделает Enter: на какой пост уйдёт ответ и кто его
увидит. ↑ ↓ — прошлые команды. Клик по `#id` у поста вставляет его в начало строки.
`post.plain_posts = false` — только команды, чтобы случайный текст не ушёл постом.

## В терминале

Тот же профиль без окна — по ssh, в скрипте, в трубе:

```
fedtail lanes                     # ленты и непрочитанное
fedtail show replies -n 20        # последние посты ленты
fedtail tail replies mentions     # новое по мере прихода
fedtail post "текст"              # новый пост
fedtail post --reply a3f "текст"  # ответ
fedtail read replies              # отметить ленту прочитанной
```

`fedtail --ui tui` — весь интерфейс в терминале, `fedtail --ui web` — во вкладке браузера.
