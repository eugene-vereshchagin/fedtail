# Настройки

Окна настроек нет — всё в конфиге. Здесь — как он устроен и где полный справочник.

## Как устроен конфиг

- ≡ → «Открыть конфиг» — файл `config.toml` в редакторе. Поправил — перезапусти fedtail.
- В нём все настройки по главам, каждая — со значением по умолчанию и пояснением.
- Вписанное тобой значение остаётся твоим, даже если в новой версии умолчание поменялось.
  Хочешь умолчание программы — закомментируй строку.
- Новая версия принесла настройки — fedtail скажет об этом при запуске.
  `fedtail --update-config` допишет их в нужные главы с пояснениями, `--rebuild-config`
  пересоберёт файл заново с твоими значениями. Старый файл останется как `config.toml.bak`.
- Рядом всегда лежит полный справочник текущей версии — `config.example.ru.toml` и
  `config.example.en.toml`. Пояснения при обновлении берутся на языке твоего файла.
