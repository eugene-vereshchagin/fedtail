# Как писать ленты

Лента в fedtail — это правило: какие посты (и какие события Активности) в неё попадают.
Каждая лента встроенных наборов — такое же правило, теми же словами, поэтому всё, что умеет
лента набора, умеет и своя, а ленту набора можно поменять.

На этой странице — весь словарь: как устроено правило, все ключи, все слова каждого ключа.
Слова — fedtail, не сервера: они проверяются при чтении конфига, и незнакомое слово никогда
молча не отбирает «ничего» — у ленты появляется предупреждение.

## Где делаются ленты

- **≡ → «Ленты…»** (или правый щелчок по ленте → «Изменить ленту…») — редактор лент, в
  каждом интерфейсе. Порядок, какие показаны, у каждой — название, картинка, источники и
  условия; пишется в `config.toml` сразу и подхватывается работающей программой.
- **`config.toml`** руками — таблица `[[lanes.custom]]` на ленту. Редактор пишет те же
  таблицы, так что они никогда не расходятся.

Лента набора, изменённая в редакторе, становится своей: `[[lanes.custom]]` с тем же именем
на её месте. «Как в наборе» убирает свою версию обратно. Из какого набора ленты —
`lanes.preset`; какие из его лент включены — `lanes.enabled` (см. [настройки](/docs/ru/config.md)).

## Как работает правило

```toml
[[lanes.custom]]
name = "pics"                     # слово ленты: латиница, цифры, _ и -
title = { ru = "Картинки", en = "Pictures" }
any = [                           # берёт пост, подходящий под ЛЮБОЕ из условий…
  { author = "followed", has = "image" },
  { source = "tags:photography" },
]
none = [{ has = "sensitive" }]    # …и не пускает подходящий под любое из этих
```

- **`any`** — условия, которые берут пост. Достаточно одного.
- **`none`** — условия, которые не пускают пост, даже если `any` его взяло.
- **Условие** — таблица ключей: подходит, когда подходит **каждый** ключ («и»). Список слов
  в ключе — **любое** из них: `author = ["followed", "mutual"]`.
- **«Или» внутри условия** — его собственное `any`, список таблиц, одна из которых тоже
  должна подойти: `{ author = "followed", any = [{ has = "image" }, { kind = "reply" }] }` —
  картинки или ответы тех, на кого подписан.
- **`source`** ленты сужает каждое условие до этих источников; без него fedtail сам
  выбирает источники, которые могут принести то, о чём спрашивают условия (условие об ответах
  тебе читает упоминания, о тегах — теги).
- **Пост, который не взяла ни одна лента**, попадает в «Неразобранное»: правило никогда не
  теряет пост.

Лента событий — `event = "favourite"` и подобные — показывает строки Активности среди своих
постов, по тихой строке на каждую («bob, ann — ★ лайкнули · 14:20 · «пост»»); лента из одних
событий — лента вроде Активности, её события непрочитаны, пока не увидены.

## Условие одной строкой

Редактор пишет условие строкой, и так же его можно набрать:

```
author: me, followed; kind: post          запятая — любое из них
text: tbilisi + georgia, грузия            в text «+» — все вместе в одной группе
any: [has: image] [kind: reply]            «или» внутри
*                                          каждый пост (ни о чём не спрашивает)
```

То же в `config.toml`: `{ author = ["me", "followed"], kind = "post" }`,
`{ text = [["tbilisi", "georgia"], ["грузия"]] }`.

## Быстрые фильтры над лентой

Над лентой кнопки двух родов; ни те, ни другие не меняют, что лента берёт, — только что из
этого видно:

- **Свои у ленты** — `switches = ["posts_only", "unread_only"]`: «Всё / Только посты /
  Новое». `switches = []` — никаких. Без ключа fedtail решает, как раньше: «Только посты» там,
  где лента читает свои источники, «Новое» — где она отмечает прочитанное.
- **У условия** — `switch = "Комменты"` на условии делает кнопку с этим словом, которая
  показывает только взятое этим условием; `shown = false` — эти посты спрятаны, пока кнопку не
  нажмут:

```toml
any = [
  { source = "home", kind = "post" },
  { source = "home", kind = "reply", switch = "Комменты", shown = false },
]
```

## Правильно ли?

- Меню поста → **«Почему это здесь?»** — какое условие его взяло и что не пустило его в
  другие ленты.
- `python3 -m fedtail --explain-lane ИМЯ` — что правило ленты делает со всем, что хранится.
- Незнакомое правилу слово, опечатка в ключе, условие, которое ни один сервер не наполнит
  (посты «для подписчиков» от чужих), — предупреждение в редакторе и в `--explain-lane`;
  условие с незнакомым словом не берёт ничего, остальная лента работает.

## Примеры

```toml
[[lanes.custom]]                  # Лента с подписанными тредами; комменты за кнопкой
name = "home_plus"
title = "Лента"
any = [
  { source = "home", kind = "post" },
  { source = "subs" },
  { source = "home", kind = "reply", switch = "Комменты", shown = false },
]

[[lanes.custom]]                  # что пропустил за ночь, по человеку
name = "overnight"
mode = "catch_up"
window = "10h"
bundle = "author"
per_author = 3
any = [{ author = "followed", kind = ["post", "quote"] }]

[[lanes.custom]]                  # лучшее на моём сервере за сутки, самые лайкнутые первыми
name = "local_best"
sort = "likes"
read = "browse"
any = [{ source = "local", age = "<1d", likes = ">5" }]

[[lanes.custom]]                  # поездка: посты о Грузии, до её конца
name = "trip"
icon = "plane"
any = [{ text = [["tbilisi"], ["georgia"], ["грузия"]], until = "2026-11-20" }]
none = [{ kind = "boost", age = ">2d", age_of = "original" }]

[[lanes.custom]]                  # лайки и бусты моих постов рядом с моими постами
name = "mine"
any = [{ author = "me" },
       { event = ["favourite", "reblog"], switch = "лайки" }]
```

Таблицы ниже собраны из кода самого fedtail: слово появляется здесь, как только программа
его знает.

## Ключи ленты

| Ключ | Что пишется | Что значит |
|---|---|---|
| `any` | список таблиц: `[{ author = "me" }, { me = "reply" }]` | Список условий: пост входит в ленту, если подходит под любое из них. |
| `badge` | `hot`, `quiet` | Цвет счётчика ленты в боковой панели: «горячий» — на что ответить, «тихий» — не к спеху. Пусто — обычный. |
| `bundle` | `author` | Посты каждого автора вместе, самый активный первым: «что я пропустил» по людям. |
| `filter_context` | `account`, `home`, `notifications`, `public`, `thread` | Серверные фильтры этого контекста скрывают или сворачивают посты ленты, из какого бы источника те ни пришли. |
| `group` | слово: `standard` или своё имя | Раздел боковой панели, где лежит лента: `standard`, `personal`, `lists`, `tags` или своё имя. |
| `hide_empty` | `true` | `true` — лента видна в боковой панели, только когда в ней что-то есть. |
| `icon` | см. ниже | Картинка ленты: из значков встроенных лент или из библиотеки (`fire`, `book`, `globe`…). Без неё — по имени ленты, у своей — как у списка. |
| `mode` | `catch_up`, `lane` | `lane` — обычная лента; `catch_up` — только пришедшее за `window`: «что я пропустил». |
| `name` | слово: `home_plus` | Имя ленты. Не меняется: окно, синк и плитки помнят ленту по нему. |
| `none` | список таблиц, как в `any` | Условия-запреты: подходящий под любое из них пост не входит, даже если `any` его пустил. |
| `open_at` | `first_unread`, `post` | Где откроется тред с карточки ленты: на посте или на первом непрочитанном комментарии (нет такого — на посте). Без ключа — по общей настройке тредов. |
| `per_author` | число: `3` | Не больше стольких постов одного автора, самых свежих: шумный не забьёт ленту. 0 — сколько есть. |
| `read` | `browse`, `through` | Как лента читается: с метками непрочитанного и счётчиками, или как свежая страница без них. |
| `sort` | `arrival`, `boosts`, `density`, `likes`, `post_time`, `replies` | Порядок постов: по приходу, по времени поста или по счётчикам (в час возраста). Лучшее лежит там, где начинается чтение. |
| `source` | см. ниже | Сужает все условия до этих источников. Без него fedtail сам берёт источники, которые могут принести нужное. |
| `start` | `true` | `true` — эта лента набора открывается первой, если стартовая лента из настроек не называет ни одной из его лент. |
| `switches` | `posts_only`, `unread_only` | Быстрые фильтры над лентой: «только посты», «только новое». `[]` — никаких. Без ключа — как в ленте до 0.22. |
| `title` | текст или по языкам: `{ ru = "Посты", en = "Posts" }` | Что показывает боковая панель. Без него показывается имя. |
| `view` | `threads` | `threads` — по карточке на тред: его пост и число новых комментариев; только треды, где есть новое. |
| `window` | `"12h"`, `"2d"` | Лента показывает только посты моложе этого срока. В `catch_up` по умолчанию 12 часов. |

## Ключи условия

| Ключ | Что пишется | Что значит |
|---|---|---|
| `age` | `"<1d"`, `">2d"` | Возраст поста: младше (`<`) или старше (`>`) срока. |
| `age_of` | `post`, `original` | Чей возраст считает `age` у буста: самого буста или оригинала. |
| `any` | список таблиц: `[{ author = "me" }, { me = "reply" }]` | Внутреннее ИЛИ: должна подойти одна из этих таблиц, а остальные ключи условия — тоже (И из ИЛИ). |
| `apart` | имя ленты: `"direct"` | Условие из `none`, которое работает, только пока показывается названная лента: личные читаются в «Личных» — там, где она включена, здесь их нет. |
| `author` | см. ниже | Кто автор поста (у буста — кто бустнул) и как он связан со мной. |
| `boosts` | `">10"`, `"<=3"`, `"5"` (не меньше) | Число бустов на момент получения поста (потом устаревает). |
| `event` | см. ниже | Событие, не пост: лайк, подписка, отписка и подобное. Такое условие подходит строкам Активности. |
| `has` | см. ниже | Что есть в посте: вложения, предупреждение, ссылки, теги, слова. |
| `id` | номер или список номеров: `"1122334455"` | Конкретный пост по его номеру на сервере (у буста подходит и номер оригинала). |
| `kind` | см. ниже | Вид поста: обычный, ответ, буст, цитата и так далее. |
| `lang` | `"ru"`, `"en"`, `"unknown"` | Язык поста — как его выставил клиент автора, а он часто ошибается. `unknown` — язык не указан. |
| `likes` | `">10"`, `"<=3"`, `"5"` (не меньше) | Число лайков на момент получения поста (потом устаревает). |
| `me` | см. ниже | Как пост связан со мной: ответ мне, упоминание, буст моего поста… |
| `parent` | `followed`, `mine`, `stranger`, `unknown` | Чей пост, на который отвечают, если он известен. |
| `priority` | число: `1` | Какое из условий `any` назвать причиной, когда подходят несколько: у кого число больше, то первое. На выбор постов не влияет. |
| `replies` | `">10"`, `"<=3"`, `"5"` (не меньше) | Число ответов на момент получения поста (потом устаревает). |
| `shown` | `false` | `false` — переключатель по умолчанию выключен, посты под ним скрыты, пока не нажмёшь. |
| `source` | см. ниже | Откуда пришёл пост: из какой ленты сервера, списка, поиска и т. д. |
| `state` | см. ниже | Что с постом у меня: прочитан, в закладках, лайкнут, в удалённых и так далее. |
| `switch` | слово на чипе: `"Комменты"` | Делает условие переключателем: над лентой появляется чип с этим словом. |
| `target` | `comment`, `my_comment`, `my_post`, `post`, `read`, `seen` | На что направлен буст, лайк или другое событие: на пост или комментарий, мой или чужой. |
| `text` | `[["a", "b"], ["c"]]` — (a и b) или c | Слова в тексте поста и предупреждении (CW). Внешний список — ИЛИ, внутренний — И. |
| `text_case` | `true` | `true` — различать заглавные и строчные буквы в `text`. |
| `text_in` | `alt`, `cw`, `name`, `poll`, `text` | Где искать `text`: в тексте, предупреждении (CW), описании медиа, вариантах опроса, имени автора. По умолчанию — текст и CW. |
| `text_regex` | `true` | `true` — слова в `text` читаются как регулярные выражения. |
| `until` | дата или момент: `"2026-11-01"` | Условие действует до этого времени; потом как будто его нет: заглушка на неделю, лента на поездку. |
| `via` | `boost`, `followed`, `list`, `mine`, `tag` | Почему пост попал в мою Ленту. |
| `visibility` | `direct`, `followers`, `local_only`, `mutuals`, `public`, `unlisted` | Кому виден пост. |

## Слова

### Слова ключа `source`

| Слово | Что значит |
|---|---|
| `bookmarks` | Мои закладки. |
| `bubble` | Серверы, выбранные админом или мной (пузырь). |
| `context` | Тред целиком, когда его открыли. |
| `direct` | Личные диалоги (последний пост каждого). |
| `favourites` | Посты, которые я лайкнул. |
| `federated` | Всё, что знает мой сервер о других серверах (не весь федиверс). |
| `home` | Моя Лента: те, на кого я подписан, их бусты, мои посты и подписанные теги. |
| `local` | Все посты моего сервера. |
| `mentions` | Посты, где меня упомянули, включая ответы мне. |
| `mine` | Мои посты и ответы. |
| `subs` | Новые комментарии в тредах, на которые я подписан. |
| `trends` | Тренды моего сервера (только просмотр). |
| `watched` | Новые посты тех, кому я включил колокольчик. |
| `list:…` | Участники списка: `list:<номер>`. |
| `tags:…` | Посты с тегами: `tags:<теги>` (любой, все или без). |
| `account:…` | Стена одного аккаунта: `account:<номер>`. |
| `remote:…` | Публичная лента чужого сервера без учётки там: `remote:<сервер>`. Токен туда не уходит. |
| `link:…` | Посты с одной ссылкой: `link:<адрес>` (Mastodon 4.3+). |
| `quotes:…` | Цитаты одного поста: `quotes:<номер>`. |
| `search:…` | Посты, найденные по словам: `search:<слова>`. |
| `rss:…` | Лента сайта как посты только для чтения: `rss:<адрес>`. |

### Слова ключа `author`

| Слово | Что значит |
|---|---|
| `bell` | Тот, кому я включил колокольчик. |
| `boosts_off` | Тот, чьи бусты я скрыл. |
| `bot` | Бот: по флажку аккаунта или по моему списку ботов. |
| `followed` | Тот, на кого я подписан. |
| `follower` | Тот, кто подписан на меня. |
| `hidden_home` | Убран из Ленты вручную («Убрать из Ленты» в профиле); подписка остаётся. |
| `in_list` | Состоит в одном из моих списков. |
| `limited` | Аккаунт под ограничением модераторов. |
| `local` | С моего сервера. |
| `me` | Я сам. |
| `mutual` | Подписаны друг на друга. |
| `new` | Аккаунту меньше 30 дней. |
| `new_follower` | Подписался на меня меньше 3 дней назад. |
| `not_follower` | Я подписан, а он на меня нет. |
| `remote` | С другого сервера. |
| `stranger` | Не подписан ни я на него, ни он на меня. |
| `@nick@host` | Один конкретный человек: `"@nick@host"`. |
| `domain:…` | Все с одного сервера: `"domain:x.org"` или несколько — `"domain:{a.org,b.org}"`. |

| Слово | Что значит |
|---|---|
| `direct` | Только упомянутым. |
| `followers` | Только для подписчиков. |
| `local_only` | Остаётся на сервере автора. |
| `mutuals` | Только для тех, с кем подписаны друг на друга (GoToSocial). |
| `public` | Виден всем. |
| `unlisted` | Не показывается в публичных лентах, но открывается по ссылке. |

| Слово | Что значит |

### Слова ключа `state`
