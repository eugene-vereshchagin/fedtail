# Keys

Every shortcut in one table.

## The window

| Key | What it does |
|---|---|
| `Ctrl+N` | a new post |
| `Ctrl+Enter` | send |
| `Ctrl+K` | find people, tags, posts |
| `Ctrl+F`, `F3`, `Shift+F3` | find in a lane, thread or profile |
| `Ctrl+L` | the command line |
| `F5` | refresh |
| `Alt+1…9` | a lane by its number (`window.number_keys`: Ctrl+1…9 too) |
| `Ctrl+W` | close a tab |
| `Esc` | close what's on top; the last one — the curtain |
| `Ctrl+Q` | quit (the cross only hides to the tray) |

Help and "What's this?" have no keys on purpose — the ≡ menu only: F1 is next to Esc, too easy to
hit by mistake.

## A lane and a thread

| Key | What it does |
|---|---|
| `j` / `k` | the next / previous post |
| `r` | reply |
| `f` | like |
| `b` | boost |
| `m` | bookmark |
| `o`, `Enter` | open the thread |
| `]` / `[` | in a thread: the next / previous top-level comment |
| `-` | in a thread: fold the branch (from a deep reply — its top comment's whole branch), again — unfold (the window) |

To turn these letters off — `window.post_keys = false`.

## The viewer and the player

| Key | What it does |
|---|---|
| `←` `→` | flip pictures; in a video — seek |
| `PgUp` `PgDn` | the next / previous video of a post |
| Space | pause |
| `M` | sound |
| `S` | save |
| `O` | open in the browser |
| `Esc` | close |
