# Finding things

Find in a lane, in every lane and on the server.

## In a lane: Ctrl+F

Finds in the open lane, thread or profile — by text, nick, `#id` and picture descriptions. It
doesn't ask the server, so it works offline too. Enter, ↓, F3 or Ctrl+F again — the next match,
Shift+Enter — the previous one. "Deeper" searches everything stored for the lane and loads the
lane down to the match.

## In every lane

The "In every lane" tick in the Ctrl+F bar: you remember a phrase but not where you saw it.
The counter says which lane the match is in, and the next match opens its lane by itself.

## People, tags, posts

The box under Write (`Ctrl+K`): a name, `@nick@server`, a link to a profile or a post, `#tag`.
Follow and Follow tag right in the results. A link to a post on another server — your server
finds and fetches it.

## A lane of several tags

Type `#грузия #georgia -#politics` in the search: one lane of all these tags opens (`+#tag` —
must be there, `-#tag` — without). The "＋ to lanes" button keeps it on the left, in the "Tags"
group.
